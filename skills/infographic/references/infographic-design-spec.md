# Infographic Design Spec Reference

Preserve these source behaviors from the upstream skill:

- Plan layouts and structure for statistical, timeline, process, comparison, geographic, hierarchical, and list infographics.
- Organize content for visual impact with title, subtitle, hero element, sections, footer, call to action, sources, and branding.
- Recommend icons, charts, images, palette, typography, dimensions, and implementation tools.
- Provide ASCII wireframes when useful.
- State limitations clearly: this skill plans graphics but does not create final graphic files or generated images.

## Common Sizes

| Platform | Size |
|---|---|
| Instagram post | 1080 x 1080 |
| Instagram story | 1080 x 1920 |
| Pinterest | 1000 x 1500 |
| X or Twitter | 1200 x 675 |
| LinkedIn | 1200 x 627 |
| Facebook | 1200 x 630 |
| A4 print | 2480 x 3508 at 300 DPI |
| Letter print | 2550 x 3300 at 300 DPI |
| Blog embed | 800 px wide, variable height |

## Design Principles

Use a clear hierarchy: title, key statistics, section headings, body content, sources. Keep whitespace generous, group related items, guide flow with arrows or numbering, and keep icons, colors, and typography consistent.
