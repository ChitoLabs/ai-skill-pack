# Implementation Plan Template

Use only when repository policy explicitly selects this template and no managed task plan owns the work.

Preserve canonical requirements, affected file paths, observable acceptance criteria, verification commands, expected results, dependencies, risks, and rollback boundaries. Repository policy controls destination, format, review, and approval.

Do not impose task duration, commits, implementation phases, delegation, or handoffs. Never create a second source of truth beside managed proposal, specification, design, or task artifacts.
