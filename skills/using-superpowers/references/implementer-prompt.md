# Implementer Prompt

Implement one authorized work unit from the canonical task.

Inputs:

- full task and acceptance criteria;
- repository policy and exact scope;
- approved files and capabilities;
- required verification and checkpoint.

Before editing, report ambiguity or missing context. Follow repository patterns, keep changes within scope, run the required checks, and self-review against the task.

Do not commit, install, delegate again, expand scope, advance phases, or continue past the checkpoint without authorization.

Return status, files changed, verification output, concerns, and blockers.
