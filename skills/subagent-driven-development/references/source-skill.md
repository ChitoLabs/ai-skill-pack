# Repository-Local Delegated Implementation Template

Use only after the user or repository policy explicitly adopts this workflow and designates its orchestration owner.

For each authorized work unit, provide isolated context, boundaries, canonical inputs, expected evidence, and a checkpoint. When delegation is available and permitted, separate implementation, specification conformance review, and technical quality review. Otherwise provide the same instructions for manual execution.

Report results and blockers to the orchestration owner. Do not create agents, commits, phases, handoffs, delivery decisions, or continuous execution without explicit authorization.
