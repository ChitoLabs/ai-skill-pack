# Craft Floor

Load after direction is settled and immediately before UI edits. The user's brief and approved design system outrank habitual preferences.

## Verify in one batched pass

- **Contrast:** body text at least 4.5:1, large text at least 3:1, visible focus, and state distinctions not carried by color alone.
- **Spacing:** tight related groups, generous separation, and more space above a heading than below it.
- **Type:** readable measure, clear hierarchy, bounded display size, resilient wrapping, and real content at each viewport.
- **Motion:** purposeful, interruptible, reduced-motion safe, and content visible by default.
- **States:** default, hover where relevant, focus, active, disabled, loading, empty, error, and success.
- **Coverage:** every brief requirement, working control, semantic relationship, and responsive state is present.

## Refuse habitual output

Unless the brief specifically earns them, reject identical card grids as page structure, generic hero metrics, repeated eyebrow labels, decorative section numbers, unnecessary modals, gradient text, glow halos, decorative glass, random side stripes, and monospace used only to signal technicality.

Use one elevation language, one radius logic, one icon family, and real or intentionally absent imagery. Never fabricate customers, metrics, prices, capabilities, or proof.

The floor checks execution. It does not choose direction or authorize scope expansion.
