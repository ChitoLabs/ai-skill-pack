# Bounded Polish Workflow

Polish is refinement, not concealed redesign. Preserve the incumbent visual world, behavior, factual copy, and everything outside the approved target.

## Establish the system

Read `DESIGN.md`, tokens, shared components, neighboring flows, and any prior critique the user identifies. Classify each issue as a missing token, one-off implementation, conceptual mismatch, or local defect. Fix the cause at the narrowest correct level.

## Triage

Fix in this order:

1. Blocked tasks, data loss, misleading state, and inaccessible paths.
2. Missing loading, empty, error, success, disabled, and permission states.
3. Flow, hierarchy, responsive behavior, and design-system drift.
4. Visual, copy, icon, image, and motion inconsistencies.
5. Dead code, unused styles, and accidental duplication introduced within scope.

## Refine

Load `craft-floor.md`. Walk the complete path using real content and representative roles, states, and input methods. Align spacing, type, tokens, controls, focus, touch targets, image behavior, and terminology with the established system. Ask before changing claims or expanding scope.

## Verify and stop

Inspect desktop and mobile together, including intermediate widths, zoom, long content, slow or missing data, and keyboard navigation. Fix all material findings in one batch, run one confirmation pass, inspect the final diff for accidental churn, and stop. Report remaining limitations rather than opening another polish loop.
