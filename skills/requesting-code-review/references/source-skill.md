# Independent Code Review Workflow

1. Confirm the explicit review scope, canonical requirements, base revision, and current revision.
2. Use an available independent review capability, or provide manual reviewer instructions when delegation is unavailable.
3. Require repository evidence and independent verification for each finding.
4. Classify findings by severity and identify file locations, impact, and suggested remediation.
5. Return advisory findings to the user or managed review owner.

Do not create commits, close review gates, approve delivery, or replace receipt, correction, recovery, or verification ownership.
