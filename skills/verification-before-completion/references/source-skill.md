# Verification Before Completion

## Evidence Gate

Before reporting a completion claim:

1. Identify the command or observation that proves the claim.
2. Run the complete check freshly.
3. Inspect relevant output, failure count, and exit status.
4. Compare evidence with the exact claim and requirements.
5. Report the actual result, including failures or limitations.

Verify delegated results independently. If a required capability is unavailable, provide precise manual verification instructions and mark the claim unverified.

In managed SDD, review, or receipt workflows, supply evidence to the designated owner. Do not issue its verdict, close gates, or decide delivery.
